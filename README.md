# Bank_Management_System

A desktop-based Bank Management System developed using **Java Swing**, **JDBC**, and **MySQL**. The application provides an easy-to-use GUI for performing basic banking operations.

## Features

- Create Bank Account
- Deposit Money
- Withdraw Money
- Fixed Deposit Management
- Loan Management
- Credit Card Management
- Transaction History
- Dashboard Overview

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL

## Database

Database Name:

```
bankdb
```

Required Tables:

- accounts
- transactions
- fixed_deposits
- loans
- credit_cards

## How to Run

1. Import the project into Eclipse.
2. Create the **bankdb** database.
3. Add MySQL Connector/J to the project.
4. Update database credentials.
5. Run `Main.java`.
